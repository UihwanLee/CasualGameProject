# 데이터 테이블

> 게임 데이터의 원본은 Google Sheets다. 이 문서는 시트(탭) 구조와 작성 규칙을 정의한다.
> 시트 값은 사람이 편집하고, 코드는 읽기만 한다(단방향). 구조를 바꿀 때는 이 문서 → 시트 → 데이터 클래스 순서로 반영한다.

## 1. 파이프라인 (M2 예정)

```
Google Sheets (사람이 편집, 탭 = 테이블)
   │ ① 다운로드: 탭마다 export URL (…/export?format=csv&gid=탭ID)
   │    시트 공유 설정 = "링크가 있는 모든 사용자: 뷰어"
   ▼
CSV → DataTool (에디터 툴): 검증 + 변환
   ▼
DataTable/*.json   ← 클라이언트와 서버가 같은 파일을 읽음. 직접 수정 금지
   ▼
DataTableService (클라) / 서버 데이터 로더
```

- 지금(M2 이전)은 `GameBootstrapper` Inspector에 같은 구조로 직접 입력한다.
- 시트 주소는 [Docs README](../README.md)의 외부 링크를 따른다.

## 2. 작성 규칙

| 규칙 | 내용 |
|---|---|
| 탭 이름 | 테이블 이름과 같게 (`Unit`, `Monster`, `Wave`, `SummonRate`, `GameConfig`). `#`으로 시작하는 탭(`#README` 등)은 변환하지 않음 |
| 1행 | 필드 이름. **C# 데이터 클래스 필드 이름과 정확히 같게** (대소문자 포함) |
| 2행부터 | 데이터. 한 행 = 데이터 클래스 객체 하나 |
| 메모 열 | 열 이름이 `#`으로 시작하면 변환하지 않음 (기획 메모용) |
| 배열 | `\|`로 구분 (예: `1\|2\|3`). 빈 칸이면 빈 배열 |
| enum | 이름 문자열 그대로 (예: `COMMON`) |
| bool | `TRUE` / `FALSE` |
| 키 | `Id`는 테이블 안에서 중복 금지 |
| 참조 | 다른 테이블 Id를 쓰는 열(예: `Wave.MonsterIds`)은 대상 테이블에 있는 Id만 사용 → DataTool이 검증 |
| 프리팹 | `Prefab` 열 값 = Unity 프리팹 이름 (풀 키로 그대로 사용) |

## 3. 테이블

### Unit → `UnitData`
| 필드 | 타입 | 설명 | 예 |
|---|---|---|---|
| `Id` | int | 고유 ID | `1001` |
| `Name` | string | 이름 | `Warrior` |
| `Tier` | enum `Tier` | 등급 (`COMMON` `RARE` `EPIC` `LEGEND` `MYTHIC`) | `COMMON` |
| `Attack` | float | 공격력 | `10` |
| `AttackSpeed` | float | 초당 공격 횟수 | `1` |
| `Range` | float | 사거리 | `3` |
| `Prefab` | string | 프리팹 이름 | `Unit_Warrior` |

### Monster → `MonsterData`
| 필드 | 타입 | 설명 | 예 |
|---|---|---|---|
| `Id` | int | 고유 ID | `1` |
| `Name` | string | 이름 | `Goblin` |
| `Hp` | float | 체력 | `30` |
| `MoveSpeed` | float | 이동 속도 | `1.5` |
| `Attack` | float | 본진 공격력 (본진 체력은 정수라 반올림) | `1` |
| `AttackSpeed` | float | 초당 공격 횟수 | `1` |
| `Range` | float | 본진 반지름 바깥으로부터의 공격 사거리 | `0.3` |
| `Gold` | int | 처치 시 골드 | `3` |
| `IsBoss` | bool | 보스 여부 | `FALSE` |
| `Prefab` | string | 프리팹 이름 | `Monster_Goblin` |

### Wave → `WaveData`
| 필드 | 타입 | 설명 | 예 |
|---|---|---|---|
| `Id` | int | 웨이브 번호 (오름차순으로 진행) | `1` |
| `MonsterIds` | int[] | 이 웨이브에 나오는 몬스터 Id 목록 (`Monster.Id` 참조) | `1\|2` |
| `SpawnWeights` | float[] | `MonsterIds`와 같은 순서·길이의 가중치. 비우면 균등 | `7\|3` |
| `Count` | int | 스폰 수 | `20` |
| `SpawnInterval` | float | 스폰 간격(초) | `0.6` |
| `TimeLimit` | float | 제한 시간(초). 지나면 다음 웨이브 | `15` |

### SummonRate → `SummonRateData`
| 필드 | 타입 | 설명 | 예 |
|---|---|---|---|
| `Tier` | enum `Tier` | 등급 | `COMMON` |
| `Rate` | float | 소환 확률(%). 전체 합계 100 | `80` |

- 해당 등급의 유닛이 `Unit` 테이블에 없으면 추첨에서 제외된다.

### GameConfig → `GameConfigData` (Key-Value)
| 필드 | 타입 | 설명 |
|---|---|---|
| `Key` | string | 설정 이름 |
| `Value` | float | 값 |

| Key | 값 | 설명 |
|---|---|---|
| `START_GOLD` | `100` | 시작 골드 |
| `SUMMON_BASE_COST` | `20` | 첫 소환 비용 |
| `SUMMON_COST_INCREASE` | `2` | 소환할 때마다 늘어나는 비용 |
| `MERGE_REQUIRE_COUNT` | `3` | 합성에 필요한 같은 유닛 수 |
| `CASTLE_MAX_HP` | `100` | 본진 최대 체력 (0이 되면 패배) |

- 지금은 같은 값을 `Define` 상수로 쓴다. M2에서 이 테이블을 읽도록 바꾼다.

## 4. DataTool 검증 항목 (M2 예정)
- 1행 필드 이름이 데이터 클래스와 일치하는지
- 타입 변환 실패 (행·열·값·기대 타입을 함께 출력)
- `Id` 중복
- 참조 무결성: `Wave.MonsterIds` → `Monster.Id`
- 배열 길이: `Wave.SpawnWeights`가 비어 있지 않으면 `MonsterIds`와 같은 길이
- `SummonRate.Rate` 합계 100
- `Prefab` 값과 같은 이름의 프리팹 존재 여부
